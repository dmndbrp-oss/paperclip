## Key Finding

**SAG-5144 constraint works but exposes a truncation mismatch.** The local model (qwen3.6) now correctly preserves existing content and only appends new sections — a significant improvement over SAG-5143 where the model rewrote the full skill. However, both target skills exceed the 10,000-char evaluate window:

| Skill | Full size | 10k window coverage |
|---|---|---|
| doc-coauthoring | 15,814 chars | 63% — Stage 3, Final Review, Tips missing from view |
| docx | 20,084 chars | 50% — Multi-Column, TOC, Headers, XML Reference missing from view |

The append-only additions correctly extend the truncated view, but since the evaluate compares `candidateSource[0:10000]` vs `skillSource[0:10000]` (identical content), delta = 0 and the gate cannot credit the new sections.

**Recommendation:** For skills > 10k chars, the workflow should either (a) chunk the skill and evaluate each chunk independently, or (b) use diff-based evaluation (compare `additions_only` not full source) rather than full-source A/B scoring.
